## Summary
Implement a mathematically correct truncated normal initializer for torch.Tensor, matching the variance compensation as done in JAX/Flax. This improves stability and reproducibility when initializing weights, especially for deep models or those sensitive to outliers.

## Features to Inject
- **Truncated Normal Initialization**: Sample from a normal distribution but truncate values outside configurable bounds (default ±2 standard deviations).
- **Variance Compensation**: Scale initialized values so the resulting tensor has the requested standard deviation (std) after truncation.
- **Bounds as Parameters**: Allow customization of lower and upper bounds (default to -2 and +2).
- **Numerical Safeguard**: Ensure clipping after transformations to prevent floating point overshoots.
- **Documentation and Examples**: Document mathematical details and add usage examples showing variance preservation and difference from torch.nn.init.trunc_normal_.
- **(Optional) Generalize for Arbitrary Mean and Fan-in Scaling**: Allow for initialization with arbitrary mean, and optionally integrate with Kaiming/Xavier fan-in scaling.

## Rationale
- Ensures more consistent variance across layers.
- Avoids extreme outliers that can destabilize early training.
- Matches JAX/Flax default for cross-framework reproducibility.
- Provides more predictable and stable training behavior, especially in deep or sensitive architectures.
