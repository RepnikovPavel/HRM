Act as a senior full-stack developer specializing in creating interactive web applications with a focus on financial data visualization. Your goal is to generate a single, self-contained HTML file that functions as a personal stock portfolio analyzer. All HTML, CSS, and JavaScript must be included within this single file.

Core Requirements:
Interface and Design:

Create a clean, modern, and professional user interface.

The app should be responsive and look good on both desktop and mobile devices.

Use a modern, flat design style with a dark theme.

Use a clear, legible font like "Inter" or "Roboto".

Implement smooth transitions and animations for a polished user experience.

Data and Functionality:

Data Simulation: For this prototype, fetch live data from NSE. Provide user an option for upload CSV file from zerodha portfolio. Analyse the user portfolio with fetched data from NSE. The data should be realistic and include:
include a csv template also to capture the data in same format
For each stock: current price, historical data (closing prices for the last 1 year), and sample fundamental/technical indicators (e.g., P/E ratio, RSI, moving averages).

Analyst recommendations (e.g., "Strong Buy", "Hold", "Sell") and a justification for each.

Dashboard View: The main view should display a summary of the portfolio, including:

Total portfolio value.

Total gain/loss (in both rupees and percentage).

A list of individual holdings with their current value, quantity, and gain/loss.

Analysis and Visualizations:

Technical Analysis: For each stock, display key technical indicators and their interpretations (e.g., "RSI is 75, indicating the stock is overbought").

Fundamental Analysis: For each stock, display key fundamental metrics (e.g., P/E ratio, Debt-to-Equity ratio, dividend yield) and a brief qualitative analysis.

Historical Data: Generate a dynamic line chart (using a library like Chart.js or D3.js, included via a CDN) to show the stock's price history over the last year. The chart should be interactive on hover.

Analyst Recommendations: Display a section that shows analyst ratings and a summary of their rationale.

Buy/Sell Signals: Based on the simulated technical and fundamental data, provide a simple, prominent recommendation for each stock: "Buy", "Sell", or "Hold." Justify this recommendation in a concise sentence.

Balancing Recommendations: Provide a simple, clear suggestion for portfolio re-balancing. This should be based on a simple rule (e.g., "Your portfolio is heavily skewed towards one sector. Consider diversifying by reallocating X% from Stock A to Stock B").

Output Format:
Generate a single file named stock_analyzer.html.

All CSS should be in a <style> tag within the <head>.

All JavaScript, including the data and the logic, must be in a <script> tag at the end of the <body>.

The code should be well-commented and easy to read.

Please provide the complete, self-contained HTML code for this application.
