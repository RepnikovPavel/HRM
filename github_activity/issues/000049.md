It looks that 'puzzle_emb' is assigned to every data item in the dataset by data item id( or index). 
I had thought it is used only for ARC AGI to be trained at inference time for evey data item.
But from the 'Trained Checkpoints' provided by the authors, 'puzzle_emb' is enabled for all 3 puzzle,
because 'puzzle_emb_ndim’ in all ‘all_config.yaml’ files are 512 which enables  'puzzle_emb'
So I doubt that there is a mistake that the model just uses  'puzzle_emb' to remember every data result.
