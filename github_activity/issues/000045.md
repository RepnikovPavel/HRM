Here are the steps for easy reproduction of training without losing time trying to discover the combinations of versions of different packages that work and without losing many hours compiling Flash Attention (very annoying!)

The secret to avoid the compilation is to use a combination that contains pre-compiled binaries (can be checked [here](https://github.com/Dao-AILab/flash-attention/releases), more info [here](https://github.com/Dao-AILab/flash-attention/issues/945#issuecomment-2948520692)). All instructions on this page focus on this


## B100 / B200

Use this docker image: `pytorch/pytorch_2.8.0-cuda12.8-cudnn9-devel`

Then login to the instance and run these commands:

```bash
pip install flash_attn
git clone https://github.com/sapientinc/HRM
cd HRM/
pip install -r requirements.txt
```

Then follow the instructions on README according to the training you plan to do

Adapt the `--nproc-per-node` field to the number of GPUs you are using

The Sudoku Extreme 1k takes ~1:30h with a single B100


## RTX 5090 / 4090 / 3090

It requires CUDA 12.8 (minimum)

It does not work with `adam-atan2` package so we use `adam-atan2-pytorch` instead

Use this docker image: `pytorch/pytorch_2.8.0-cuda12.8-cudnn9-devel`

Then login to the instance and run these commands:

```bash
pip install flash_attn
git clone https://github.com/sapientinc/HRM
cd HRM
sed -i 's/adam-atan2/adam-atan2-pytorch/g' requirements.txt 
pip install -r requirements.txt
sed -i 's/adam_atan2/adam_atan2_pytorch/g' pretrain.py
sed -i 's/AdamATan2/AdamAtan2/g' pretrain.py
sed -i 's/lr=0,/lr=0.0001,/g' pretrain.py
```

Then follow the instructions on README according to the training you plan to do

Adapt the `--nproc-per-node` field to the number of GPUs you are using

The Sudoku Extreme 1k takes less than 2h with a single 5090
And it can take ~1h 35min if you set the `eval_interval` to the same value as `epochs` (default is 20000)
