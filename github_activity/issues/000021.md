## Comments (2)

### Comment by @imoneoi at 2025-08-04T04:13:16Z

1. We tried H&M&L and it has similar performance than H&L. Probably 2-3 levels are sufficient
2. As the segment number depends on latent state (e.g. more compute for hard problem, less for simpler ones), we need a policy function $\pi(z_t) \mapsto \{ halt, continue\}$. Deep Q-learning is a simple solution, there're definitely more efficient RL methods to explore. Hyperparameter optimization methods are not state-dependent.
